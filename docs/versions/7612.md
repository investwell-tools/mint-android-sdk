## Dependency Implementation

Mint SDK can be integrated in one of two ways: via **GitHub Packages** or via a **local repo**.

---

### Method 1 — GitHub Packages Implementation

**Step 1 — Add credentials to `gradle.properties`**

```properties
githubToken=<YOUR_GITHUB_PAT>
githubUser=<YOUR_GITHUB_USERNAME>
```

**Step 2 — Add the GitHub Packages repository**

In `settings.gradle.kts` (or `settings.gradle`), inside `dependencyResolutionManagement { repositories { ... } }`:

```kotlin
maven {
    url = uri("https://maven.pkg.github.com/investwell-tools/mint-android-sdk")
    credentials {
        username = providers.gradleProperty("githubUser").get()
        password = providers.gradleProperty("githubToken").get()
    }
}
```

**Step 3 — Add the dependency**

In your app-level `build.gradle.kts`:

```kotlin
implementation("com.investwell.tools:mint-sdk:*.*.+")
```

---

### Method 2 — Local Repo Implementation

**Step 1 — Add the local repo**

In `settings.gradle.kts`, inside your repositories block:

```kotlin
maven { url = uri("../build/repo") }
```

**Step 2 — Add the dependency**

In your app-level `build.gradle.kts`:

```kotlin
implementation("com.investwell.tools:mint-sdk:*.*.+")
```
